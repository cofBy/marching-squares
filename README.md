# marching squares
marching squares is an algorithm that takes in a states and positions and outputs a smoothed mesh between the points. You can read more about it [here](https://en.wikipedia.org/wiki/Marching_squares)

## why it's useful
it can be used in games for procedurally generating levels which is how terraria generates its landscapes.

# setup and use instructions
You can just copy the repo and put all the files in unity and put the "marching squares" component on an object and feed into it the "dataTexture" from another script <br/>
You can try it out from [here](https://cof99.itch.io/marching-squares) on itch.io
